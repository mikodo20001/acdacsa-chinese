## 1. 系统简介

### 1.1 系统概述

本系统是基于YOLOv8深度学习框架开发的医学细胞检测与分类系统，主要用于识别显微镜图像中的三种血细胞类型：

- **RBC (Red Blood Cell)**: 红细胞
- **WBC (White Blood Cell)**: 白细胞
- **Platelet**: 血小板

### 1.2 系统特点

- ✅ 自动化检测，准确率超过90%
- ✅ 检测速度是人工分析的50倍以上
- ✅ 支持批量处理和单张图像检测
- ✅ 提供可视化分析工具
- ✅ 友好的图形用户界面

### 1.3 应用场景

- 临床血常规分析
- 病理图像自动筛查
- 医学教学与研究
- 细胞计数与分类
- 异常细胞检测

## 2. 环境配置

- CPU: Intel i5或同等性能
- RAM: 8GB

## 3. 数据准备流程

### 3.1 数据收集

收集高质量的细胞显微图像，推荐规格：
- 分辨率: 1024x1024或更高
- 格式: JPG, PNG
- 数量: 每类至少100张（总计300+）

### 3.2 数据标注

#### 使用LabelMe标注工具

1. **安装LabelMe**:
```bash
pip install labelme
```

2. **启动标注工具**:
```bash
labelme
```

3. **标注步骤**:
   - 点击"Open Dir"选择图像目录
   - 使用矩形工具框选细胞
   - 输入标签名称（RBC/WBC/Platelet）
   - 保存为JSON文件（与图像同名）

4. **标注规范**:
   - 边界框要紧贴细胞边缘
   - 完全可见的细胞才标注
   - 重叠细胞尽量分别标注
   - 标签名称严格使用RBC、WBC、Platelet

### 3.3 格式转换

将LabelMe的JSON格式转换为YOLO格式：

```bash
cd scripts
python labelme_to_yolo.py \
    --labelme_dir ../data/raw \
    --output_dir ../data/processed \
    --classes RBC WBC Platelet
```

输出结果：
```
data/processed/
├── images/          # 图像文件
│   ├── img001.jpg
│   ├── img002.jpg
│   └── ...
└── labels/          # YOLO格式标注
    ├── img001.txt
    ├── img002.txt
    └── ...
```

YOLO标注格式说明：
```
# 每行一个检测框
# 格式: class_id x_center y_center width height
0 0.5 0.5 0.1 0.1  # RBC
1 0.3 0.3 0.15 0.15  # WBC
2 0.7 0.7 0.05 0.05  # Platelet
```

### 3.4 数据集划分

按8:1:1比例划分训练集、验证集和测试集：

```bash
python split_dataset.py \
    --source_dir ../data/processed \
    --output_dir ../data \
    --train_ratio 0.8 \
    --val_ratio 0.1 \
    --test_ratio 0.1 \
    --seed 42
```

划分结果：
```
data/
├── train/
│   ├── images/  # 训练图像
│   └── labels/  # 训练标注
├── val/
│   ├── images/  # 验证图像
│   └── labels/  # 验证标注
└── test/
    ├── images/  # 测试图像
    └── labels/  # 测试标注
```

## 4. 模型训练流程

### 4.1 配置数据集文件

编辑 `configs/dataset.yaml`:

```yaml
path: ../data
train: train/images
val: val/images
test: test/images

nc: 3
names:
  0: RBC
  1: WBC
  2: Platelet
```

### 4.2 开始训练

#### 基础训练（推荐新手）

```bash
cd scripts
python train.py --data ../configs/dataset.yaml
```

#### 自定义参数训练

```bash
python train.py \
    --data ../configs/dataset.yaml \
    --model yolov8s.pt \
    --epochs 100 \
    --batch 16 \
    --imgsz 640 \
    --optimizer AdamW \
    --lr0 0.01 \
    --project ../outputs/runs \
    --name cell_detection_exp1
```

参数说明：
- `--model`: 预训练模型（yolov8n/s/m/l/x.pt）
- `--epochs`: 训练轮数
- `--batch`: 批次大小（根据GPU内存调整）
- `--imgsz`: 输入图像大小
- `--optimizer`: 优化器类型
- `--lr0`: 初始学习率
- `--project`: 输出项目路径
- `--name`: 实验名称

### 4.3 监控训练过程

训练过程中会实时输出：
```
Epoch    GPU_mem    box_loss    cls_loss    dfl_loss    Instances        Size
1/100      3.42G      1.234       0.567       1.234          512         640
2/100      3.42G      1.123       0.523       1.189          512         640
...
```

关键指标说明：
- `box_loss`: 边界框回归损失
- `cls_loss`: 分类损失
- `dfl_loss`: 分布焦点损失
- mAP: 平均精度（越高越好）

### 4.4 训练输出

训练完成后，输出目录结构：

```
outputs/runs/cell_detection/
├── weights/
│   ├── best.pt      # 最佳权重（mAP最高）
│   └── last.pt      # 最后一轮权重
├── results.png      # 训练曲线图
├── confusion_matrix.png  # 混淆矩阵
├── F1_curve.png     # F1曲线
├── P_curve.png      # Precision曲线
├── R_curve.png      # Recall曲线
├── PR_curve.png     # PR曲线
└── args.yaml        # 训练参数
```

### 4.5 恢复中断的训练

如果训练中断，可以从检查点恢复：

```bash
python train.py \
    --data ../configs/dataset.yaml \
    --resume ../outputs/runs/cell_detection/weights/last.pt
```

## 5. 模型评估与分析

### 5.1 模型评估

评估模型在测试集上的性能：

```bash
cd scripts
python evaluate.py \
```

```
  mAP@0.5:0.95 : 0.7800
  Precision    : 0.9200
  Recall       : 0.8900

各类别性能 (mAP@0.5):
  RBC       : 0.9300
  WBC       : 0.8800
  Platelet  : 0.9200
```

### 5.2 数据可视化

生成数据分布和统计图表：

```bash
python visualize.py \
    --labels_dir ../data/train/labels \
    --output_dir ../outputs/visualizations
```

生成的图表包括：
1. `class_distribution.png` - 类别分布直方图
2. `position_scatter.png` - 细胞位置散点图
3. `bbox_size_distribution.png` - 边界框尺寸分布
4. `aspect_ratio_distribution.png` - 宽高比分布
5. `statistics_report.txt` - 统计报告文本

### 5.3 结果分析

#### 解读评估指标

- **Precision（精确率）**: 模型预测为正样本中真正为正样本的比例
  - 高Precision：误报少

- **Recall（召回率）**: 所有正样本中被正确识别的比例
  - 高Recall：漏检少

- **mAP@0.5**: IOU阈值为0.5时的平均精度
  - 主要评估指标，越高越好

- **mAP@0.5:0.95**: IOU阈值从0.5到0.95的平均精度
  - 更严格的评估标准

#### 性能基准

| 性能等级 | mAP@0.5 | 应用场景 |
|---------|---------|---------|
| 优秀 | > 0.90 | 临床应用 |
| 良好 | 0.80-0.90 | 辅助诊断 |
| 一般 | 0.70-0.80 | 科研教学 |
| 需改进 | < 0.70 | 继续训练 |

## 6. 模型部署与应用

### 6.1 单张图像检测

```bash
cd scripts
python inference.py \
    --model ../outputs/runs/cell_detection/weights/best.pt \
    --source ../data/test/images/cell_001.jpg \
    --output ../outputs/predictions \
    --conf 0.5 \
    --show
```

参数说明：
- `--conf`: 置信度阈值（0-1），推荐0.25-0.5
- `--iou`: NMS的IOU阈值，默认0.45
- `--show`: 显示检测结果窗口

### 6.2 批量检测

处理整个文件夹的图像：

```bash
python inference.py \
    --model ../outputs/runs/cell_detection/weights/best.pt \
    --source ../data/test/images \
    --output ../outputs/predictions \
    --conf 0.3
```

批量检测会自动：
- 处理所有图像
- 统计检测结果
- 保存标注图像
- 输出统计报告

### 6.3 置信度阈值调优

根据应用场景选择合适的置信度阈值：

| 应用场景 | 推荐阈值 | 说明 |
|---------|---------|------|
| 临床诊断 | 0.5-0.7 | 高精度，减少误报 |
| 辅助筛查 | 0.3-0.5 | 平衡精度和召回 |
| 科研统计 | 0.2-0.3 | 高召回，减少漏检 |

## 7. 图形界面使用

### 7.1 启动界面

```bash
cd gui
python cell_detection_gui.py
```

### 7.2 界面功能介绍

界面分为三个主要区域：

1. **左侧控制面板**
   - 模型设置：加载训练好的模型
   - 检测参数：调整置信度和IOU阈值
   - 图像操作：加载、检测、保存

2. **右侧图像显示区**
   - 显示原始图像和检测结果
   - 自动调整图像大小以适应窗口

3. **底部结果区**
   - 显示检测统计信息
   - 详细的检测结果列表

### 7.3 操作流程

1. **加载模型**
   - 点击"加载模型"按钮
   - 选择训练好的.pt文件（通常选择best.pt）
   - 等待加载完成提示

2. **加载图像**
   - 点击"加载图像"按钮
   - 选择要检测的细胞图像
   - 图像会显示在右侧

3. **调整参数**（可选）
   - 拖动置信度滑块调整检测阈值
   - 拖动IOU滑块调整NMS阈值

4. **开始检测**
   - 点击"开始检测"按钮
   - 等待检测完成（进度条显示）
   - 查看标注后的图像和统计结果

5. **保存结果**
   - 点击"保存结果"按钮
   - 选择保存位置和文件名
   - 保存标注后的图像

## 8. 进阶技巧

### 8.1 数据增强策略

在训练配置中添加数据增强：

```yaml
# configs/train_config.yaml
hsv_h: 0.015      # 色调增强
hsv_s: 0.7        # 饱和度增强
hsv_v: 0.4        # 亮度增强
degrees: 10.0     # 旋转角度
translate: 0.1    # 平移
scale: 0.5        # 缩放
fliplr: 0.5       # 水平翻转
mosaic: 1.0       # Mosaic增强
```

### 8.2 迁移学习技巧

1. **冻结骨干网络**（少量数据）：
```python
# 修改train.py
model.freeze(10)  # 冻结前10层
```

2. **渐进式解冻**：
```python
# 先训练50轮冻结模式
model.freeze(10)
model.train(epochs=50)

# 再解冻训练50轮
model.unfreeze()
model.train(epochs=50)
```

### 8.3 多尺度训练

增强模型对不同尺寸细胞的检测能力：

```bash
python train.py \
    --data ../configs/dataset.yaml \
    --imgsz 640 \
    --scale 0.5  # 允许50%的尺度变化
```

### 8.4 模型集成

使用多个模型进行集成检测：

```python
from ultralytics import YOLO

# 加载多个模型
model1 = YOLO('best1.pt')
model2 = YOLO('best2.pt')
model3 = YOLO('best3.pt')

# 集成预测
results1 = model1('image.jpg')
results2 = model2('image.jpg')
results3 = model3('image.jpg')

# 使用加权融合或投票策略合并结果
```

## 9. 故障排除

### 9.1 常见错误及解决方案

#### 错误1: CUDA Out of Memory

**症状**:
```
RuntimeError: CUDA out of memory
```

**解决方案**:
1. 减小batch_size
```bash
python train.py --data config.yaml --batch 8
```

2. 减小图像尺寸
```bash
python train.py --data config.yaml --imgsz 512
```

3. 使用梯度累积
```bash
# 在代码中设置accumulate=4
```

#### 错误2: 找不到标注文件

**症状**:
```
Warning: 未找到标注文件 xxx.txt
```

**解决方案**:
1. 检查标注文件命名是否与图像一致
2. 确认labels和images目录结构正确
3. 重新运行格式转换脚本

#### 错误3: 模型不收敛

**症状**: Loss持续不下降或NaN

**解决方案**:
1. 降低学习率
```bash
python train.py --lr0 0.001
```

2. 检查数据标注质量
3. 增加训练数据量
4. 使用预训练权重

#### 错误4: 检测结果不准确

**症状**: 漏检或误检严重

**解决方案**:
1. 调整置信度阈值
```bash
python inference.py --conf 0.3
```

2. 增加训练轮数
```bash
python train.py --epochs 200
```

3. 使用更大的模型
```bash
python train.py --model yolov8m.pt
```

4. 收集更多训练数据
5. 改进数据标注质量

### 9.2 性能优化建议

1. **GPU利用率低**
   - 增加batch_size
   - 增加num_workers
   - 使用混合精度训练

2. **推理速度慢**
   - 使用更小的模型（yolov8n）
   - 减小输入图像尺寸
   - 使用TensorRT加速
   - 批量处理而非单张

3. **内存占用高**
   - 减小batch_size
   - 减小缓存大小
   - 关闭不必要的可视化
